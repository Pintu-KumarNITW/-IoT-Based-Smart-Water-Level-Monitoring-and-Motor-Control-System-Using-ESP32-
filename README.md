# IoT-Based Smart Water Level Monitoring and Motor Control System Using ESP32

## Overview
This project is an IoT-based smart water level monitoring and motor control system developed using the ESP32 microcontroller. It continuously measures the water level using an ultrasonic sensor and automatically controls a water pump through a relay module. The system helps conserve water, prevents tank overflow, and avoids dry running of the motor.

## Features
- Real-time water level monitoring
- Automatic motor ON/OFF control
- Overflow prevention
- Dry-run protection
- LCD display for water level status
- LED indicators
- Buzzer alerts
- ESP32-based implementation
